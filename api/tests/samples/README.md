# Sağlayıcı yanıt örnekleri (yalnızca test)

Bu dosyalar sağlayıcıların **belgelenmiş yanıt biçimini** taklit eder; uyarlayıcıların ayrıştırma,
durum eşleme, sayfalama ve hata davranışını test etmek için elle yazılmıştır.

* Takımlar, ligler, oyuncular ve skorlar **kurgusaldır** ("Örnek FK", "Test Spor" ...).
* Gerçek veri değildir; uygulamada hiçbir yerde gösterilmez veya tohum verisi olarak kullanılmaz.
* Gerçek API anahtarı geldiğinde (M-G1) uyarlayıcılar canlı yanıtlarla ayrıca doğrulanacaktır.
